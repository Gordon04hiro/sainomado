## 子ども口座（未成年口座）とは

子ども口座は、0歳から作れる、子ども名義の証券口座です。口座の名義は子どもですが、実際の手続きや運用は、親権者（ふつうは親）が代わりに行います。子どもが18歳になると、成年の口座に切り替わります。

証券会社によって「未成年口座」「こども口座」など呼び方が違いますが、中身は同じです。開くには、先に親権者の口座があることや、子ども名義の銀行口座が必要なことが多いです。

## 2027年1月から「こどもNISA」が始まる

2026年の税制改正で、これまで18歳以上が対象だったNISAのつみたて投資枠が、未成年にも広がりました。いわゆる「こどもNISA」で、子ども口座の中で始めます。

| 項目 | こどもNISA |
|---|---|
| 始まる時期 | 2027年1月 |
| 対象 | 0〜17歳 |
| 積み立てられる額 | 年60万円まで（非課税で持てるのは合計600万円まで） |
| 買えるもの | つみたて投資枠の対象の投資信託を、毎月などの積立で |
| 引き出し | 中学校に入る年からは、本人の教育費・生活費のために、本人の同意などの書類を出せば引き出せる。それより前は災害などの場合に限る |
| 18歳になったら | 成年のNISA（つみたて投資枠）に自動で移る |

引き出しの条件を守らないと、それまでの利益に税金がかかるので気をつけましょう。くわしい手続きは、証券会社の案内で確かめてください。

## メリット

1. **教育資金を、家計と分けて管理できる**：子ども名義なので、「この子のためのお金」がはっきりします。生活費に紛れて使ってしまうことも防げます
2. **長い時間をかけて増やせる**：0歳から始めれば、大学入学まで15年以上あります。時間が長いほど、積立の効果が出やすくなります
3. **2027年からは、こどもNISAで非課税にできる**：利益に税金がかからない枠を、子ども1人あたり年60万円まで使えます
4. **親のNISAの枠を使わずに済む**：親のNISAは老後資金、子ども口座は教育資金と、目的ごとに分けられます
5. **お金の話をするきっかけになる**：大きくなったら、自分の口座を一緒に見ながら、お金の増え方を話せます

## デメリットと注意点

1. **入れたお金は子どものものになる**：親が困ったときに引き出して使う、ということはできません。親の生活費の予備にはならないと考えておきましょう
2. **贈与の形を整えないと「親のお金」と見られることがある**：親が子どもに知らせずに管理しているだけだと、実質は親の財産（名義預金）と判断されることがあります。毎年の入金を振込で行う、贈与の記録（贈与契約書など）を残す、子どもが理解できる年になったら伝える、といった形を整えておくと安心です
3. **贈与税の基礎控除は年110万円**：1人の子どもが1年間にもらうお金が110万円を超えると、贈与税の申告が必要になることがあります
4. **元本は保証されない**：投資なので、使いたい時期に値下がりしていることもあります。大学入学の数年前からは、少しずつ預金に移すなどの準備が要ります
5. **こどもNISAは、すぐには引き出せない**：中学校に入る年より前は、原則として引き出せません。近いうちに使う予定のお金は、預金で持っておきましょう

## 親のNISAで貯める場合との違い

教育資金は、親のNISAで積み立てることもできます。

| | 子ども口座（こどもNISA） | 親のNISA |
|---|---|---|
| 名義 | 子ども | 親 |
| 非課税の枠 | 子ども1人あたり年60万円・合計600万円 | 親1人あたり年360万円・合計1,800万円 |
| 引き出し | 中学校に入る年から、教育費などのために条件つきで | いつでも自由に |
| 使い道 | 子どものため | 自由（老後資金と兼ねられる） |
| 贈与の手続き | 必要（年110万円が基礎控除） | 不要 |

親のNISAの枠に余裕があるなら、まずは親のNISAで教育資金を貯めるのも十分な選択肢です。自由に引き出せるので、急な出費にも対応できます。

## 子ども口座が向いている家庭・向いていない家庭

**向いている家庭**
- 親のNISAの枠を、すでに老後資金で使い切りそう
- 教育資金を家計と分けて、手をつけずに貯めておきたい
- 祖父母から孫への援助を、子ども名義でまとめて管理したい
- 児童手当を、毎月そのまま子どものために積み立てたい

**向いていない家庭**
- 家計の予備のお金（生活費の半年分くらい）がまだ貯まっていない
- 数年以内に使う予定のお金を貯めたい
- 親のNISAの枠に、まだ十分な余裕がある

## 始める前に決めておきたいこと

1. **何に使うか**：大学の学費、留学、独り立ちの資金など
2. **いつ使うか**：使う時期から逆算すると、投資に回せる期間が決まります
3. **毎月いくら入れるか**：教育費の目安は[教育費はいくらかかる？](#a-kyouikuhi)を参考にしてください

ライフプラン診断では、教育費がかかる年と、住宅ローンなどの支出が重なる時期を、95歳までのお金の流れで確かめられます。

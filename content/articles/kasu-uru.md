:::ポイント
- 家賃から、管理委託料・空室・修繕・固定資産税・ローンの返済・税金を引いた「手残り」で考える
- 貸している間にローンの残りが減る分、あとで売るときの手取りは増える
- 自宅を売るときの3,000万円特別控除は、住まなくなってから3年目の年末まで。値上がりした家ほど、この期限が大きく効く
:::

## 家賃がそのまま入るわけではない

家を貸すと、家賃から次のお金が出ていきます。

| 出ていくお金 | 目安 |
|---|---|
| 管理会社への管理委託料 | 家賃の3〜8%ほど |
| 空室の期間 | 入居者が入れ替わるときの空き。年1か月分ほどを見ておく |
| 管理費・修繕積立金（マンション） | 住んでいたときと同じく、持ち主が払う |
| 修繕・入退去の費用 | 設備の交換、原状回復、入居者募集の広告料など |
| 固定資産税・火災保険 | 持ち主が払う |
| 住宅ローンの返済 | 残っていれば返済は続く |
| 不動産所得の税金 | 家賃から費用・利息・減価償却費を引いた所得にかかる |

家賃月11万円のマンションでも、空室・管理委託料・管理費・修繕・固定資産税を引くと、年に60万円ほどが出ていきます。ローンの返済が月5.5万円あると、手残りはほぼ0か、少し持ち出しになることもあります。

## 毎月は持ち出しでも、売るときに取り戻すことがある

毎月の手残りがマイナスでも、貸している間にローンの残りは減っていきます。あとで売るとき、その分だけ手取りが増えます。

たとえば、今売れば2,800万円のマンション（ローン残り1,500万円）を10年貸してから売る場合を計算すると、次のようになります（家賃月11万円、価格は年1.5%ずつ下がる前提）。

| | 今売る | 10年貸してから売る |
|---|---|---|
| 貸している間の手残り | — | 約▲92万円（持ち出し） |
| 売ったときの手取り | 約1,178万円 | 約1,362万円 |
| 合計 | 約1,178万円 | 約1,270万円 |

毎月は少し持ち出しでも、合計では貸した方が約92万円多く残る計算です。ただし、家の価格がもっと下がる地域や、空室が長引く場合は逆転します。

## 3,000万円特別控除の期限に注意

自宅を売ったときの利益（譲渡所得）からは、最大3,000万円を差し引ける特例があります。ただし、使えるのは**住まなくなった日から3年目の年末までに売る場合**です。その間に人に貸していても使えますが、期限を過ぎると使えなくなります。

値上がりした家では、この期限が大きく効きます。たとえば、3,000万円で買った家が4,500万円で売れる場合、2026年に住まなくなったなら次のようになります。

- 2029年の年末までに売る：特例で税金は0円
- それより後に売る：税金が300万円以上かかることがある

家賃の手残りがプラスでも、期限を過ぎてから売ると、合計では今売る場合より少なくなることがあります。「いつか売るかもしれない」なら、期限の年までに方針を決めておくのが大切です。

:::現場メモ
- 住宅ローンを借りたまま家を貸すのは、原則として銀行の承諾が必要です。転勤など事情によっては認められますが、賃貸用のローンへの借り換えを求められることもあります。貸すと決める前に、まず銀行に相談しましょう
- 一度貸すと、入居者がいる間は自由に売りにくくなります。いずれ売るつもりなら、期間を決めて貸す「定期借家」という契約にしておくと、売るときの選択肢が広がります
:::

## 判断のポイント

| 貸す方が向きやすい | 売る方が向きやすい |
|---|---|
| 家賃がローンの返済と費用を大きく上回る | 家賃を入れても毎月の持ち出しが大きい |
| 駅に近いなど、借り手が見つかりやすい | 空室が長引きそうな地域 |
| 価格が下がりにくい地域 | 価格が下がりやすい（築年数が進む）家 |
| 将来また住む予定がある | 値上がりしていて、3,000万円特別控除を使いたい |

## 自分の家で計算する

サイのまどの「貸す・売る 比べる診断」では、今売れそうな価格・ローン・家賃・費用を入れると、毎年の手残りと、その年に売ったときの手取りを年ごとに並べて、今売る場合と比べられます。3,000万円特別控除の期限も自動で反映します。今売れそうな価格は「売却相場の目安」で、町名ごとの国のデータから調べられます。

:::まとめ
- 家賃ではなく、費用・ローン・税金を引いた手残りで考える
- 貸している間にローンが減る分、売るときの手取りは増える。価格の下がり方とのかね合いで決まる
- 3,000万円特別控除は住まなくなってから3年目の年末まで。値上がりした家ほど期限が大事
:::

> 計算は目安です。不動産所得や譲渡所得の税金は、個別の事情で変わります。実際の申告は税務署や税理士に確かめてください。
